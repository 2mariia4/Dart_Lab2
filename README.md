### Ответы на вопросы

1. В чём разница между полем класса и обычной переменной в функции?

Поле класса принадлежит конкретному объекту и существует столько, сколько живёт объект. Каждый объект имеет собственную копию поля. Доступ к полю осуществляется через объект (task.title) или через this внутри методов

Обычная переменная в функции существует только во время выполнения этой функции и уничтожается при выходе из неё. Она недоступна вне функции и не связана с каким-либо объектом

2. Что такое конструктор и зачем он нужен?

Конструктор - специальный метод класса, который автоматически вызывается при создании объекта через Todo(...)

Конструктор нужен для: 
инициализации полей объекта начальными значениями;
валидации входных данных;
установки значений по умолчанию для полей, которые не передаются явно;
генерации вычисляемых значений;

3. Зачем нужен @override перед toString()? Что будет если его убрать?

@override - аннотация, которая сообщает компилятору что этот метод переопределяет метод из родительского класса. Все классы наследуются от Object, у которого есть мметод toString()

Зачем он: Компилятор проверяет, что метод с таким именем существует в родителе. Если есть опечатка, то компилятор выдастошибку

Что будет если убрать: программа всё равно будет работать, но потеряется защита от опечаток в имени метода

4. Чем статическое поле static int _counter отличается от обычного поля?
Сколько копий этого поля существует в программе?

Статическое поле принадлежит классу целиком, а не его копиям. Оно существует в единственном экземпляре на всю программу

Обычное поле принадлежит каждому объекту отдельно. Если создать 10 зада будет 10 разных id

При создании каждой новой задачи _counter увличивается на 1, это значение записывается в id нового объекта. Если объектов будет 500, копия будет одна

5. Что означает нижнее подчёркивание в _counter?

Нижнее подчёркивание перед именем идентификатора делает его приватным для файла. К _counter можно обращаться только внутри того же файла, это защищает внутреннюю реализацию класса от вмешательства из вне
